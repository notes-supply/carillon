# Working agreement

Build the product in `docs/product/` as the smallest coherent production-shaped system.

Write idiomatic Rust and TypeScript. If it looks like a Python developer wrote it, it is bad Rust or TypeScript.

Prefer fewer lines, less state, and fewer moving parts. Complexity must earn its place.

Keep native runtime and platform semantics with their owning adapters. Use mature public APIs.

Keep `mise run check` green. Test observable behavior, not implementation trivia.
